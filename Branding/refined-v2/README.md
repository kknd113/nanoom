# Held n — refinement 02

Developed from the user's selected direction, October 28, 2026. Preserves the lowercase n sheltering one person. This is an evolution of the first symbol, not a new naming direction.

## Optical changes

- Stroke reduced from 13 to 11.5 units on a 128-unit grid, retaining round caps.
- Arch span tightened from 60 to 58 units; the shoulder/stem relationship is less pronounced.
- Dot moved upward from y=81 to y=76; radius reduced from 8 to 7.25. The person sits closer to the shelter and the opening feels less like a doorway.
- Mark is optically centered in the 1024-square icon, with opaque light and dark backgrounds and no baked-in iOS corner mask.

The before/after board includes 24/32/48-pixel renderings. The primary symbol keeps its central dot at these sizes. These are visual checks, not a user recognition study.

## Outlined wordmark

nanoom-wordmark-v2.svg is custom vector lettering: single-storey a, rounded n, circular o pair and a shared-arch m. The warm, geometric rhythm relates to the symbol. All letters are paths/circles rather than font-dependent text, so the exported logotype does not depend on an installed font. The custom wordmark is a display asset; the app's readable native system typography remains appropriate for interface text.
